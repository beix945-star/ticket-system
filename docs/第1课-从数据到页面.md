# 第 1 课：让一份数据变成工单页面

今天只要理解一个关系：**数据 → React 组件 → 浏览器里的页面**。

第一版由助手搭建，练习目标是能解释、修改并验证它。今天不用学习后端、数据库或登录。

## 先认识三个名字

- HTML：告诉浏览器“这里是标题、段落、列表”。
- CSS：控制颜色、大小、间距和排列。
- JavaScript：保存数据、处理操作、更新页面。TypeScript 在它的基础上检查数据类型。

React 帮我们把界面拆成组件。`.tsx` 文件可以同时写 TypeScript 和描述界面的 JSX。JSX 看起来像 HTML，但可以插入 JavaScript 表达式。

## 1. 打开 App.tsx，看第一段

```tsx
type Ticket = {
  id: number
  title: string
  description: string
  status: 'pending' | 'processing' | 'completed'
  createdAt: string
}
```

`Ticket` 是工单的格式约定。`id: number` 表示编号是数字，`title: string` 表示标题是文字。

`status` 只允许三个指定的值。把它写成 `done`，类型检查会提示错误。这些类型约束用于开发时检查，不能代替后续后端的运行时参数校验。

`createdAt` 暂时用字符串表示日期。

## 2. 第二段：三条模拟工单

```tsx
const tickets: Ticket[] = [
  // 三个工单对象
]
```

`const` 声明变量，`tickets` 是变量名称。`Ticket[]` 表示这是一个数组，里面每一项都符合 `Ticket` 的格式。

`[]` 包围整个数组，`{}` 包围一条工单，各条工单用逗号隔开。今天先修改里面的文字即可。

## 3. 第三段：把状态值转成中文

```tsx
const statusLabels = {
  pending: '待处理',
  processing: '处理中',
  completed: '已完成',
}
```

这是一份对应表。`statusLabels['pending']` 得到的就是“待处理”。

## 4. 第四段：一张卡片是一个组件

```tsx
function TicketCard({ ticket }: { ticket: Ticket }) {
  return (
    // 描述这张卡片的界面
  )
}
```

`TicketCard` 是一个接收工单数据并返回界面的函数。React 组件名称以大写字母开头。

这里的 `ticket` 是通过 props 从外部传进来的工单。冒号后的 `{ ticket: Ticket }` 规定它的类型。你今天先知道“传入一条工单，显示一张卡片”，不需要马上记住所有语法。

```tsx
<h3>{ticket.title}</h3>
```

`h3` 是标题标签。中间的 `{ticket.title}` 取出工单标题，放进页面。

`className="ticket-card"` 对应 CSS 里的 `.ticket-card`，所以外观由 `App.css` 决定。

## 5. 第五段：把三条数据变成三张卡片

```tsx
{tickets.map((ticket) => (
  <TicketCard key={ticket.id} ticket={ticket} />
))}
```

`map` 会依次处理数组里的每条数据，为每条数据生成一个 `TicketCard`。

- `ticket={ticket}`：把当前这条工单交给卡片。
- `key={ticket.id}`：给每张卡片稳定且唯一的标识，帮助 React 区分它们。

所以添加第四条工单后，不必再手写一张卡片，列表会跟随数组变化。

## 你的第一次练习

1. 把第一条工单的标题改成“这是我的第一条工单”。保存，观察浏览器。
2. 把它的 `status` 从 `pending` 改成 `processing`。保存，观察文字和颜色。
3. 复制一条工单，添加到数组末尾，编号改成 **1004**，标题和描述自行填写。
4. 检查页面是否出现四张卡片，“全部工单”后的数字是否变成 4。

不用修改 TicketCard 或 JSX 来增加第四张卡片。留意每条数据之间的逗号。

## 怎么知道练习成功了

- 页面显示新标题，状态变成“处理中”。
- 页面有四条不同编号的工单，总数为 4。
- 在根目录运行 `./project.sh build` 没有类型错误。

想一想：为什么只添加了一条数据，页面就多了一张卡片？能用自己的话回答，今天的主要目标就完成了。
